# ChannelKhoj 

### Find your DTH channels. Without the hassle.

ChannelKhoj is a multi-provider DTH channel finder designed to help users in India quickly search and discover television channels and their channel numbers.

## Supported Providers

- Tata Play
- Airtel Digital TV
- Sun Direct
- d2h
- Dish TV

## Features

- Search channels by name or channel number
- Browse channels by DTH provider
- Filter by language and HD/SD
- Find free-to-air channels where data is available
- Simple and responsive interface

- JavaScript
